#Random-Name-Picker

Demand by senior high school teacher,I created this repository.

##format:
name
name
...
name
number;

##The name divided by space that you enter will be add to the name list,and the number you enter in the last line is the number
of the random name;

##example:

##input:
John
Alice
Tom
Armstrong
Dick
Caixukun
2

##output:
Dick
Tom
